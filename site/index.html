How to use.

  1. Download the zip you picked — or clone the repository. Each zip carries a START-HERE.md with both paths.
  2. Instantiate it from a clone of landing-starter. The bootstrap fills every placeholder and fails loudly if one is left behind: $ node bootstrap.mjs ../my-app --template template-v2 --name "My App" --accent "#7c3aed" Drop --template for Classic (the default); run node bootstrap.mjs --list to see the catalog.
  3. Customize the tokens at the top of assets/css/styles.css, then serve it — node serve.mjs. There is no build step.

Templates distilled and reimplemented from public sources — the Genex desktop app is MIT. Typefaces: Zalando Sans SemiExpanded & Geist Mono (SIL OFL).
